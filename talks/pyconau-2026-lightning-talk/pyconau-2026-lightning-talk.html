Wrap anything, capture everything, change nothing.

wrapture is wrapt plus capture. A sibling project to wrapt, built on its monkey patching machinery.

Three jobs, done the hard way

  • Monkey patching: setattr and hope nobody else patched it too
  • Testing: Mock invents return values, and a patched method no longer runs the real code
  • Tracing: SDK calls in the code, or auto-instrumentation only for frameworks it knows

All three are the same move:
wrap a call site, by name.

At a glance


place  = wrapture.binding(OrderService, "place")
charge = wrapture.binding(Gateway, "charge")
record = wrapture.binding(Ledger, "record")

with wrapture.timeline(place, charge, record) as tape:
    OrderService().place(500)

print(tape.tree())
        

OrderService.place(amount=500)  -> {'id': 'ch_500', 'amount': 500}
  Gateway.charge(amount=500, currency='USD')  -> {'id': 'ch_500', 'amount': 500}
  Ledger.record(entry={'id': 'ch_500', 'amount': 500})  -> 'led_ch_500'

None of these classes import wrapture.

1. Monkey patching


charge = wrapture.binding("myapp.gateway", "Gateway.charge")

# or raises(), transforms_args(), transforms_result(), decorates()
charge.on_call.returns({"id": "ch_TEST"})

charge.apply()
...
charge.remove()   # original restored

# or scope it
with charge:
    ...
  • Declare, then apply: a typo fails on the line that made it
  • Wrappers compose with other decorators and patches
  • Useful on its own, with nothing else switched on

2. Testing


charge.on_call.raises(TimeoutError("gateway timed out"))

with wrapture.timeline(charge, refund, ledger):
    service.place("o-7", 400)
    service.cancel("o-7")

    charge.events.raising(TimeoutError).assert_once()
    ledger.events.assert_never()
    refund.events.assert_never()
  • The real code runs; you watch how calls actually flowed
  • Assert on what didn't happen on the error path
  • Test code with no injectable seams at all

3. Ad-hoc tracing


# wrapture.toml
[[observe]]
target = "myapp.orders:OrderService"
match = "*"
exclude = "_*"

[[observe]]
target = "myapp.payments:Gateway"
name = ["charge", "refund"]
data = { changes = ["PR-1234", "PR-1250"] }

[[sink]]
type = "jsonlines"
path = "trace.jsonl"
          

$ python -m wrapture manage.py runserver

# or, with autowrapt installed,
# no launcher at all:
$ AUTOWRAPT_BOOTSTRAP=wrapture \
    python manage.py runserver

A nested call tree from an application you cannot modify or redeploy.
Static data tags every event, so a PR can ship the config that watches the code it touched.
Process the JSON Lines yourself, or convert it for Perfetto and other tools:
python -m wrapture.tools convert --format chrome -o trace.json trace.jsonl

One mechanism, one config

  • The binding that stubs a method in a test is the one that traces it in production
  • The config that prints a call tree is the config that ships a trace to observability tools
  • Point at your own methods by name: no SDK calls, no waiting for a framework integration
  • What starts as a monkey patch or a test assertion grows into observability, with no rewrite

OpenTelemetry, no code changes


# add to the same wrapture.toml
[otel]
service_name = "flask-shop"
signals = ["traces", "metrics", "logs"]

[otel.environment]
exporter_otlp_endpoint = "http://localhost:4318"
  • The same recorded events, exported live to any OTLP backend as traces, metrics and correlated logs
  • Open source: Jaeger, Grafana Tempo, SigNoz, OpenObserve. SaaS: Honeycomb, Datadog, Grafana Cloud, New Relic
  • Trace identity arrives and leaves in W3C traceparent headers, so two observed services join one distributed trace
  • pip install wrapture[otel], then add [otel] to the same wrapture.toml
