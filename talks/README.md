# Talks

Slide decks for talks about wrapture, one directory per talk.

- `pyconau-2026-lightning-talk/`: five minute lightning talk introducing
  the project at PyCon AU 2026.

The decks are single reveal.js HTML files that load reveal.js from a CDN,
so they need a network connection but no build step. Open the file in a
browser to present. Press `s` for the speaker notes window, `f` for
fullscreen, and `Esc` for the slide overview.
